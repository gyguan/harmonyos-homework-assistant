# Issue #12｜家长文字录入与多任务拆分

## 目标

家长可直接粘贴老师发来的整段作业文字，App 自动拆成多个待确认作业，不要求先截图。

主链路：

`老师文字 → TextArea → HomeworkImportService.parseText → LocalHomeworkAssignmentParser → CandidateAssignment[] → 家长确认 → 发布`

截图 OCR 与手工文字共用同一个 `HomeworkAssignmentParser`。

## 支持格式

### 每条都写学科

```text
1. 语文背诵第12课
2. 语文完成练习册P35
3. 数学口算20题
4. 数学练习册P32
5. 英语听读U4，明天检查
```

预期：5 项。

### 学科标题只写一次

```text
语文：
1. 背诵第12课
2. 完成练习册P35
数学：
1、口算20题
2、练习册P32
英语：听读U4
```

后续未重复写学科的任务继承最近一个明确学科，预期：5 项。

### 分号连接

```text
语文背诵第12课；语文完成练习册P35；数学口算20题；数学练习册P32；英语听读U4
```

预期：5 项。

## 保护规则

- 空文字不进入解析；
- 没有拆出明确任务时，不覆盖当前 Candidate；
- 截图 OCR 成功但未拆出任务时，也不清空已有 Candidate；
- 每条 Candidate 保留对应 Source Evidence；
- 不新增后端、工作流或额外领域层。

## 本地验收

1. 家长 → 收作业；
2. 粘贴上述 5 条样例；
3. 点击“智能整理作业”；
4. 确认生成 5 项；
5. 进入家长确认并发布；
6. 切换学生 Today，确认新任务可见；
7. 输入无法识别的纯文本，确认已有整理结果未被清空。
