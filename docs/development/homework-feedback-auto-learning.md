# AI 作业整理反馈：提交即自动尝试生效（V41）

## 用户体验

家长在 AI 整理结果中点击「反馈 AI 整理问题」，只需选择问题类型，并说明错在哪里或修改正确内容。**不需要维护老师、填写触发词、手动勾选保存经验，也不需要第二次提交。**

后端一次反馈请求在一个事务中完成：验证家庭与学生归属 → 保存反馈与证据 → 比对该批次/候选的服务端不可变 AI 初稿快照 → 尝试推导最小适用线索 → 与已启用的规则冲突检查 → 保存可停用的学生专属经验 → 返回真实结果状态。

| processingStatus | 含义 | 客户端提示 |
|---|---|---|
| `APPLIED` | 成功持久化一条自动经验（FEEDBACK_AUTO） | 已自动形成当前学生的经验，下次符合范围时参考 |
| `PENDING_EVIDENCE` | 未找到匹配初稿、文本片段不一致或没有足够的正确做法 | 反馈已保存，暂不生成可能误导作业的经验 |
| `REVIEW_REQUIRED` | 对同一范围/线索存在相互矛盾的活跃经验，或容量达到上限 | 反馈已保存，冲突经验未自动启用 |

## 规则约束

- 数据只写入既有 `homework_teacher_experience`，`origin='FEEDBACK_AUTO'`，保留 `source_feedback_id` 供追溯。不会因单次家庭反馈修改全局 `homework_organizer_rule`，也不会训练底层模型权重。
- 根据 `familyId + studentId` 严格隔离；有可信教师身份时按该老师归属，否则按学生科目范围记录，不虚构具体老师。
- 缩写反馈只有在家长给出具体解释，且来源能识别出**唯一可疑数字简写**时，才尝试 `朗读国13 → 朗读国*` 之类的线索；不能明确时保留原文精确匹配。
- 漏项、拆项、错误内容/科目、日期及重复等反馈，只记录**该段原文可复用的纠错提示**，不能把一次的日期、题号、页码或学生回答泛化成全局规则。
- 没有服务端不可变 AI 初稿或家长提供的片段与初稿不符，不自动生效。图片在未识别当前图片的文本时只能附加「看到完全一致的线索后才可参考」的条件提示，不保证每张图片自动匹配。
- 同一条已停用经验不会因重试而被静默重新启用；原有手工 `promote` API 和旧数据维持兼容。
- 重新整理**新的一批作业**时动态读取经验；已生成的历史结果不会自动重写。

## 测试

`HomeworkFeedbackAutoLearningServiceTest`：缩写与普通反馈自动提取、证据不匹配、冲突、幂等、跨学生/科目隔离、文本后续 Prompt、图片条件提示。

`HomeworkFeedbackSubmitAutoApplyTest`：真实提交入口一笔事务内先落反馈、再保存自动经验，且状态准确；证据不全不得伪称已生效。

Flyway `V41__homework_feedback_auto_learning.sql` 扩展经验来源约束；数据库启动与既有发布、录音、定时作业 E2E 继续走原 CI。

后续可引入受限 AI 审核及经过家长确认的结构化差异做更精准的规则归纳，但不能用模型无验证地概括整班或所有老师的作业模式。
