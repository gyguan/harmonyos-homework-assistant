# V0.2 作业解析与确认回归样例

目标：覆盖深圳小学家庭常见老师作业消息，验证“解析尽量准确，家长确认兜底”。

## 20 个核心样例

### CASE-01 基础多学科
输入：`语文背诵第12课；数学练习册P32；英语听读U4，明天检查。`
预期：3 项；学科分别为语文/数学/英语；英语截止明天。

### CASE-02 同学科多任务
输入：`语文：1.背诵第12课 2.完成练习册P35 数学：1.口算20题 2.练习册P32 英语：听读U4`
预期：5 项；同学科可拆成多任务。

### CASE-03 分号分隔
输入：`语文默写词语；语文预习第13课；数学订正错题；英语复习U4`
预期：4 项。

### CASE-04 英文分号
输入：`语文朗读第12课;数学口算20题;英语听读U4`
预期：3 项。

### CASE-05 周五截止
输入：`数学：完成练习册P32，周五检查`
预期：1 项；截止周五；教材位置 P32。

### CASE-06 星期三截止
输入：`英语：听读U4，星期三检查`
预期：1 项；截止星期三；教材位置 U4。

### CASE-07 具体日期截止
输入：`语文：背诵第12课，9月15日检查`
预期：1 项；截止 9月15日。

### CASE-08 中文页码范围
输入：`数学：完成练习册32-35页`
预期：1 项；教材位置 32-35页。

### CASE-09 P页码范围
输入：`数学：练习册P32-35`
预期：1 项；教材位置 P32-35。

### CASE-10 单元
输入：`英语：复习第4单元`
预期：1 项；教材位置 第4单元。

### CASE-11 今晚
输入：`语文：默写本课词语，今晚完成`
预期：1 项；截止今晚。

### CASE-12 同一条两个动作
输入：`语文：背诵第12课，完成练习册P35`
预期：2 项。

### CASE-13 并列动作
输入：`英语：听读U4，并复习单词`
预期：2 项。

### CASE-14 通知过滤-带书
输入：`语文：明天带语文书`
预期：0 项。

### CASE-15 通知过滤-校服
输入：`语文：明天穿校服返校`
预期：0 项。

### CASE-16 通知过滤-家长会
输入：`语文：周五召开家长会`
预期：0 项。

### CASE-17 通知与作业混合
输入：`语文背诵第12课；明天带语文书；数学口算20题`
预期：2 项作业，带书通知过滤。

### CASE-18 学科继承
输入：`数学：1.口算20题 2.订正错题 3.预习下一课`
预期：3 项，均为数学。

### CASE-19 OCR换行风格
输入：`语文\n背诵第12课\n数学\n完成练习册P32\n英语\n听读U4`
预期：3 项。

### CASE-20 家长手工修订
输入：解析结果学科或截止时间不准确。
预期：确认页可修改学科、标题、截止时间、教材/页码，也可新增和删除 Candidate 后再发布。

## 产品原则

- 不追求本地规则 100% 自动正确；不确定项通过低置信度和家长确认兜底。
- 班务通知不进入学生作业清单。
- OCR 与粘贴文字继续复用同一个 `HomeworkAssignmentParser`。
- 后续接 LLM 时替换 Parser 实现，不改变确认和发布闭环。
