# 小伴作业 V2｜练习题内容与体验规范

> 状态：Active  
> 适用范围：Practice 预置题库、后续新增/更新题库、题目生成脚本、题目校验、练习作答与结果展示  
> 强制性：任何新增或修改练习题、套卷、提示语、选项、答案、解析前必须先阅读并遵守本规范。

## 1. 目标与优先级

练习模块首先服务孩子“看得懂、愿意做、做得对、能复盘”，而不是追求题量或复杂功能。

当实现、历史数据、生成脚本与本规范冲突时：

1. 已发布历史 Attempt / Result 不允许被破坏；
2. 新发布的题库内容必须遵守本规范；
3. 需要改变本规范时，先修改本文件并在同一 PR 中说明原因，再修改题库或实现；
4. 不允许通过兼容分支、测试特判或跳过校验绕过本规范。

## 2. 当前题库基线

当前预置题库目标范围：

- 地区：深圳；
- 学段：小学；
- 年级：二年级；
- 学期：上学期；
- 科目：语文、数学、英语；
- 题库类型：`TEXTBOOK_SYNC`（教材同步）与 `EXTRACURRICULAR`（课外拓展）。

教材同步题必须基于**已经明确的教材版本、单元或知识点**组织，不得仅凭“二年级大概学什么”生成。若出版社/版本尚未在项目数据中明确，应先确认教材信息，不得在题目中隐式假设。

课外拓展允许增加观察、逻辑、阅读和生活应用，但仍必须保持二年级可理解、可独立完成，不能用高年级知识包装成“拓展”。

## 3. 内容设计原则

每一道题都必须满足：

- **年龄适配**：语言、情境、运算量和推理长度适合二年级学生；
- **生活化**：优先校园、家庭、社区、公园、地铁、图书馆、购物、运动、天气等儿童熟悉场景；
- **具体可理解**：避免成人化、抽象化、过度书面化表述；
- **真实变化**：不能只替换数字、姓名或物品形成机械重复题；
- **一个明确任务**：题干必须清楚说明“要做什么”，不能靠猜测出题意；
- **可独立作答**：题目本身提供解题所需信息，不依赖不可见图片、外部材料或上下文；
- **不超纲**：教材同步题不引入当前年级/学期之外的核心知识。

当前题库以文本为主，不依赖生成图片。题干中禁止出现“看图、图中、图片、画面”等需要缺失视觉材料才能作答的表述。未来若恢复视觉题，必须先明确合法素材来源、数据模型和校验规则，再更新本规范。

## 4. 科目要求

### 4.1 语文

- 覆盖字词积累、量词、近反义词、句子、标点、阅读理解和生活表达等二年级能力；
- 阅读材料应原创、简短、情节或信息完整；
- 不使用超出二年级理解能力的生僻表达作为主要考点；
- 题目重点考理解和运用，不做无意义机械抄写。

### 4.2 数学

- 教材同步题围绕当前学期明确知识点；
- 计算题之外应有适量生活应用题；
- 题干中的数量、单位和关系必须完整且无歧义；
- 不引入小数、百分数、负数、方程、面积/体积公式、质数、因数分解等当前基线之外的知识；
- 数学拓展可以训练规律、位置、比较、等量代换和简单逻辑，但不能依赖高年级公式。

### 4.3 英语

- **题干/操作说明必须有中文引导**，保证孩子先理解“这道题要做什么”；
- 考查内容可以是英语单词、短句、句型或超短阅读；
- 场景优先家庭、校园和儿童日常；
- 提示语使用中文辅助理解，不能把理解英文题目要求本身变成额外障碍；
- 不使用明显超出当前词汇/句型范围的内容作为正确答案判断依据。

## 5. 选择题规则

选择题是重点质量门禁。

### 5.1 独立性

- 每道题必须读取和展示自己的 `options`；
- 题目切换时，题干、选项、当前答案状态必须一起更新；
- 不允许通过共享 UI 快照、固定首题数据或模板残留导致“题干变了但选项没变”。

### 5.2 唯一正确答案

单选题必须：

- 至少提供 3 个有效选项；
- 每个选项都有非空、互不相同的 `key` 和可见 `label`；
- 同一题内选项文本不能重复或语义等价；
- `answerSpec` 必须且只能指向一个实际存在的选项；
- 题干必须保证只有一个明确、可辩护的正确答案。

### 5.3 干扰项

- 干扰项必须围绕本题生成，属于同一知识域；
- 应是孩子可能真实混淆的近似答案，而不是明显荒谬的凑数项；
- 不得为了制造错误选项而引入题干没有给出的条件；
- 不得让正确答案因为长度、措辞精细度、格式或单位明显突出。

### 5.4 正确答案位置

- 正确答案不得长期固定在第一个或某一个位置；
- 当前预置单选题以 A/B/C 为主时，每套纯单选卷应尽量均衡分布；
- CI 对每套包含足够单选题的套卷检查答案位置分布，防止重新出现固定答案模式。

## 6. 提示语规则

每道题必须提供**针对本题**的提示，不允许统一模板提示。

当前预置题库提示格式：

`关键词：……`

要求：

- 提示必须来自题干中的关键词、关键条件、关键数字、关键动作或关键句型；
- 数学：帮助识别数量关系、单位、运算方向，不直接列出最终算式或答案；
- 语文：帮助定位关键词、上下文、句意或表达要求；
- 英语：用中文帮助理解关键词、句型或操作要求；
- 提示只提供思考入口，不泄露正确选项文本或答案；
- 禁止“仔细想一想”“先读题再选择”“结合生活经验判断”等可套在任何题上的泛化提示。

## 7. 答案与解析

- `answerSpec` 必须可由题目本身确定；
- `explanation` 必须解释为什么，而不是只重复答案；
- 数学答案需检查数值、单位和运算关系；
- 英语答案需检查词义、句型和题干中文要求的一致性；
- 解析语言应适合二年级儿童和家长共同阅读；
- 不允许同一道题存在两个等价正确答案却只标记其中一个。

## 8. 套卷组织

预置练习以套卷为核心：

- 一个 Paper 对应明确主题/能力点；
- 当前标准套卷保持 12 题，除非产品规范明确调整；
- 同一套卷内题目应覆盖不同角度，不能 12 题只换数字或名词；
- `title`、`description`、`tags` 必须真实反映训练内容；
- `TEXTBOOK_SYNC` 与 `EXTRACURRICULAR` 必须明确区分；
- 难度以 L1/L2 为当前主范围，拓展不等于超纲。

## 9. 发布与版本规则

预置题库的**唯一源文件**位于：

`backend/src/main/resources/practice/preset/`

前端：

`entry/src/main/ets/data/practice/PresetPracticeCatalog.ets`

是生成文件，**禁止手工编辑**。

修改已发布题目时：

1. 不覆盖数据库中已经发布并产生练习记录的 Paper 版本；
2. 修改内容应发布新的 `version`；
3. 历史版本通过现有归档机制退出当前目录，但历史 Attempt / Result 必须继续可追溯；
4. 题目 ID、Paper ID、版本关系必须稳定可解释；
5. 修改 JSON 后运行生成脚本和内容校验。

标准命令：

`python scripts/generate_practice_catalog.py`

`python scripts/validate_practice_content.py`

## 10. 练习过程体验不可回退

内容更新不得破坏已经确立的练习体验：

- 每次开始练习创建独立 Attempt；
- 未提交 Attempt 不进入完成统计；
- 可上一题/下一题、题号导航、保存答案、每题笔记、查看提示；
- 有未答题时交卷必须确认；
- 重练创建新 Attempt，不覆盖旧结果；
- 支持“再练一遍”和“只练错题”；
- 上次答案/笔记默认隐藏，仅作为显式参考，不自动填入当前答案；
- 套卷详情展示最近练习记录并可查看全部；
- 结果页显示套卷名称、练习次数、得分、正确率、耗时、答题回顾、答案、解析和笔记；
- 结果页使用标准返回语义，不返回已提交答题页。

## 11. Phone / Pad 可读性不可回退

Phone 与 Pad 都是一等形态：

- 不通过设备型号判断字号和布局；
- 基于真实可用宽度做连续或能力型适配；
- Phone 保持紧凑可用；
- 宽屏适当放大题干、选项、输入、提示、笔记、题号和操作按钮；
- 内容保持合理最大可读宽度并居中，不能简单铺满 Pad；
- 深层练习页面复用 `DeepPageHeader`；
- 不新增 Feature 私有 600/840/1080 等设备断点。

## 12. 新增/修改练习题的 Definition of Done

提交前逐项确认：

- [ ] 已阅读本规范；
- [ ] 年级、学期、科目、题库类型正确；
- [ ] 教材同步题有明确教材/知识点依据；
- [ ] 题干二年级学生可理解，且不依赖缺失图片；
- [ ] 英语题干有中文引导；
- [ ] 每道选择题选项属于当前题目，文本非空且互不重复；
- [ ] 单选题只有一个明确正确答案；
- [ ] 正确答案位置没有固定规律；
- [ ] 每题提示都与题干关键词直接相关且不泄露答案；
- [ ] 解析解释“为什么”，不是只重复答案；
- [ ] 同卷不存在大面积机械换词/换数；
- [ ] 已发布内容通过新 version 演进，不原地覆盖历史；
- [ ] 已运行 `generate_practice_catalog.py`；
- [ ] 已运行 `validate_practice_content.py`；
- [ ] CI Practice content catalog gate 通过。

## 13. 规范变更

本规范是 Practice 内容的长期基线。后续如果产品范围扩展到其他年级、学期、地区、教材版本、视觉题或新的题型：

- 先更新本规范与对应 schema/validator；
- 再新增内容；
- 不通过放宽校验、跳过 CI 或增加特殊 case 直接塞入题库。
