# V0.1 单家庭产品收敛基线（历史文档）

- Status: **Superseded by V2**
- Superseded: 2026-09-16

> 本文只用于理解 V0.1 当时为什么选择轻量单家庭范围，不再作为当前产品或技术实现依据。

## 仍然有效的边界

以下原则继续有效：

- 产品服务单家庭、多孩子；
- 家长负责导入 / 确认，孩子负责执行，AI 负责整理与辅导；
- AI 不直接发布老师作业；
- 学生首页优先回答“我现在应该做什么？”；
- 家长首页聚焦完成情况、异常、提交和验收；
- 不建设学校 / 班级 SaaS、教师后台、排行榜、社交广场；
- 不引入微服务、MQ、API Gateway、工作流引擎等与家庭级产品不匹配的重型基础设施。

## 已被 V2 替代的内容

V0.1 的以下设计已经过时：

- “不显式建立 Family”已经失效：当前云端使用轻量 `family` 作为真实数据安全边界；
- “页面 → HomeworkStore / HomeworkService”不再是目标前端结构；
- 新 V2 Feature 使用 `ViewModel + Repository`，`HomeworkStore` 只作为迁移期兼容数据源；
- 学生一级导航不再是“今天 / 作业 / 我的”，而是 **首页 / 作业 / 学习 / 我的**；
- Assignment 已扩展为统一 SCHOOL / EXTRA 模型；
- 日期、科目、状态筛选和 Pad 增强属于 V2 正式能力；
- 响应式业务布局不再依赖固定窗口断点。
