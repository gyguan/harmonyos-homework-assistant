# 小伴作业｜产品特性清单 V2

> 状态：**UI 全面重构基线**  
> 适用平台：HarmonyOS Phone / Pad  
> 产品范围：**单家庭作业管理 + AI 学习辅导**，不扩展为学校、班级或教师 SaaS。  
> 关联文档：`product-design-v1.md`、`ui-design-v1.md`。V1 的产品定位继续有效，但后续 UI 重构与功能实现优先以本清单为准。

---

## 1. 产品目标

小伴作业不是“功能很多的教育 App”，而是一个面向家庭日常学习的 **作业执行系统**：

- 家长负责：收作业、整理、确认、关注异常、验收结果；
- 孩子负责：知道下一项做什么、完成作业、需要时问小伴、提交结果；
- AI 负责：把信息整理成任务、在学习过程中提供提示和分步辅导；
- 系统负责：把每天的作业变得清楚、可执行、可跟踪。

核心原则：

> **孩子少管理、多行动；家长少操作、多掌握；AI 融入流程、不占据流程。**

# 2. V2 信息架构

## 2.1 学生端一级导航

Phone 底部导航：

1. **首页**
2. **作业**
3. **学习**
4. **我的**

Pad 使用左侧导航，信息架构保持一致。

### 首页

回答一个问题：

> 我现在应该做什么？

主要内容：

- 今日日期与学生信息；
- 今日完成度；
- 下一项作业；
- 今日剩余作业；
- 最近提醒；
- 快捷入口：作业、错题本、学习空间、课外作业。

### 作业

回答：

> 我有哪些作业？怎么快速找到？

主要能力：

- 全部 / 课内 / 课外分类；
- 按科目筛选；
- 按日期筛选；
- 按状态查看；
- 列表模式；
- 日历模式；
- 科目模式。

### 学习

回答：

> 除了完成老师作业，我还可以学什么？

主要入口：

- 当前学习空间；
- AI 小伴；
- 错题本；
- 阅读推荐；
- 实践任务；
- 兴趣拓展；
- 课外作业。

### 我的

保持轻量：

- 学生档案；
- 学校 / 年级 / 班级；
- 学习提醒；
- 字号 / 声音；
- 我的收藏；
- 家长管理入口。

# 4. 课外作业扩展能力

课外作业是 V2 信息架构中必须 **预留** 的能力，但当前不要求一次做完。

## 4.1 作业类型统一

所有 Assignment 都应具备：

```text
assignmentType:
- SCHOOL      课内作业
- EXTRA       课外作业
```

避免未来另建一套完全独立的数据模型。

## 4.2 课外作业入口

预留位置：

- 学生首页快捷入口；
- 学生“作业”页：全部 / 课内 / 课外；
- 学生“学习”页课外作业专区；
- 作业日历；
- 家长首页快捷入口；
- 家长手工创建任务入口。

## 4.3 未来课外作业类型

建议逐步支持：

- 阅读任务；
- 口语 / 朗读；
- 体育锻炼；
- 兴趣拓展；
- 实践任务；
- 家务 / 生活能力；
- 社会实践；
- 自定义任务。

### 第一阶段不要做

- 积分商城；
- 排名；
- 班级 PK；
- 社交广场；
- 学校运营后台。

# 6. Phone UI 约束

本轮重构必须遵守：

1. **Phone 不出现固定主从左右分栏。**
2. 列表点击进入独立详情页。
3. 学习空间为单任务页面。
4. AI 小伴使用独立页面 / 抽屉，不和学习内容强制并排。
5. 顶部筛选保持轻量，复杂条件放到底部面板。
6. 主要操作按钮宽度充足、位置稳定。
7. 一个页面只突出一个主动作。
8. 不因为 Preview / 设备宽度识别异常切换成 Pad 布局。

# 7. Pad UI 特性

Pad 不是放大的 Phone，而是提升浏览和学习效率。

## PAD01｜作业总览

布局：

```text
左侧导航 | 作业筛选与列表 | 作业详情
```

能力：

- 科目筛选；
- 日期筛选；
- 课内 / 课外；
- 列表选中后右侧直接查看详情；
- 不足以容纳两个完整内容区时自动退回单列。

## PAD02｜学习空间

布局：

```text
作业 / 题目 / 资料 | AI 小伴
```

默认只显示居中可读的当前作业；学生主动点击“问小伴”后再进入上述双栏。

宽度充分时可增加左侧任务列表：

```text
今日任务 | 当前作业 | AI 小伴
```

要求：

- 每栏必须满足最小可读宽度；
- 不允许为了“Pad 设计”强制压缩内容；
- 分屏 / 竖屏自动降级。

## PAD03｜家长进度 / 验收

布局：

```text
作业列表 | 提交证据 / 验收详情
```

适合家长快速逐项查看照片、状态和备注。

## PAD04｜日历 / 课外专区

大屏可并列展示：

```text
月历 / 日期任务 | 课外作业推荐与列表
```

# 8. 跨端响应式原则

V2 不再用“Phone / Pad 型号”直接决定页面布局。

应使用：

> **实际容器可用宽度 + 内容最小可读宽度**

决定是否可以进入多栏。

规则：

- Phone 默认单列；
- 列表与详情在窄窗口永远通过页面跳转；
- Pad 只有在实际空间足够时使用双栏 / 三栏；
- 分屏、折叠屏、自由窗口自动重新计算；
- 多栏条件是“内容能否完整显示”，不是某个固定设备宽度。

---

# 9. 视觉设计原则

1. HarmonyOS 原生感；
2. 白 / 浅灰为主要背景；
3. 一个主品牌色；
4. 学科色只作为标签、小图标等辅助色；
5. 卡片减少层层嵌套；
6. 重要动作清楚，不依赖装饰说明；
7. 儿童友好，但不幼稚；
8. 不做游戏化排名和强刺激奖励；
9. 家长端比学生端更克制；
10. Phone 留白优先于塞满信息。

# 11. V2 非目标

至少当前阶段不做：

- 学校 / 班级 SaaS；
- 教师后台；
- 家校 IM；
- 同学社交；
- 排行榜；
- 积分商城；
- 海量题库；
- 搜题答案库；
- 在线直播课；
- 复杂租户模型。

这些能力会显著提高系统复杂度，但并不会改善“一个家庭每天把作业做好”这一核心目标。

---

# 12. V2 核心验收标准

本轮 UI / 产品重构完成后，至少满足：

1. 学生打开首页 3 秒内能知道下一项作业是什么；
2. 作业可按 **科目 + 日期** 快速过滤；
3. 作业天然支持 **课内 / 课外** 两种类型；
4. Phone 所有核心流程都可以在单列布局完整完成；
5. Phone 不再出现被压缩的左右分栏；
6. Pad 在空间足够时能够提升浏览和学习效率，而不是简单放大 Phone；
7. 学生完成一次作业最多经过：开始 → 学习 / 辅导 → 提交；
8. 家长导入一次老师作业最多经过：原文 → AI 整理 → 确认发布；
9. 家长可以清楚知道今天是否存在逾期、待订正、待验收；
10. 后续增加课外阅读、实践、体育等任务时，不需要重新设计一级信息架构和 Assignment 主模型。
