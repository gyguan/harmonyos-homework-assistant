# ADR 0013：整理结果采用按上下文版本隔离的进程内缓存

- 状态：Accepted
- 关联：#591 P1

重复导入允许复用无风险提示的结构化 AI 初稿，同时每个新批次必须留下自己的来源证据和快照。缓存不承担权限、发布、数据库幂等或家长确认职责。

使用有 TTL、LRU 条数和总响应字节限制的进程内组件。键包含家庭/学生及完整输入、日期、模型/Prompt/规则/经验版本。每次查询从数据库读取当前经验状态，包括无文字图片请求；禁用/修改经验立即使旧键不可用。模型调用期间上下文改变则不写入旧缓存。图片内容只参与哈希，不保存在缓存值中。没有跨进程共享缓存，没有 Redis 或新持久化表，重启无需数据迁移。

缓存命中也重做通用质量校验；只保存非空且无风险提示的响应。命中不会跳过 Service 的家庭授权或批次证据保存。缓存值序列化以隔离不同请求的可变集合。原文只在私有响应内驻留内存，不写日志；TTL 后最迟在下一次访问或每分钟清理任务中释放引用。

默认开启，可用环境变量整体关闭。并发相同请求不合并正在执行的推理，以避免共享请求取消/权限上下文和长锁。命中统计记录零新增调用/Token；未命中 provider 缺失 usage 继续记 unavailable。性能报告分开冷/热请求，固定样本质量验收不因缓存而放宽。

相较共享缓存，本方案多实例命中率较低，但保留当前模块化单体边界，容易灰度与回退。真实准确率与费用收益必须通过 VERIFIED 金标及真实 provider 运行确认。
