# ADR 0014：看不清的独立图片片段共用一次复核预算

- 状态：Accepted
- 关联：#591 P1

图片首轮仍同时返回全图独立来源与候选。可靠文字可做定向文字复核；文字本身不清楚而有有效小范围定位时，第二轮改为该区域的无损原像素裁剪。一次请求的文字/视觉复核互斥，总调用上限仍为两次。缺少位置、来源身份冲突或范围过大时不猜测、不重做整图 OCR，不引入重试循环。

视觉复核只允许修改该不清楚来源的转录与显式关联候选。Java 校验几何、结构、引用、差异范围、不可删除初稿和风险改善；AI 负责转录、分类和业务语义。不能由 Java 根据作业关键词决定补/删任务。复核失败完整保留初稿，继续人工可编辑确认。

SourceDocument schema 3 的可选 revisions 保存来源前后状态及带理由的候选差异，保留第一轮独立证据。原有文本原文不被修改，未涉及来源不变。缺省 revisions 为空保证 schema 2 与历史 JSON 可读。仍使用 V43 evidence_json，不新增表，不修改历史 Flyway，不持久化像素。该数据与快照在同一事务内按家庭/学生/批次保存，原有授权/读取/重启恢复测试扩展覆盖。

默认开启，但仅有明确 UNCLEAR 风险和有效有限位置才进入。支持配置关闭，参与缓存上下文。自动锐化/对比度变换可能抹去笔画，缺少 VERIFIED 质量证据前不启用。实际图片/缓存 usage 缺失保留 unavailable；裁剪像素数不能充当实际 Token。真实质量收益需另行跑固定金标。
