## 二、在 AGC 创建项目与应用

1. 用浏览器打开 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，登录已实名的华为开发者账号。
2. 顶部导航 → **我的项目** → 点击 **添加项目**。
   - 项目名称：建议填 `小伴作业`（可改，仅用于后台管理）。
   - 数据处理位置：选择 **中国**。
3. 进入新项目后，点击 **添加应用**，按如下填写：
   - **平台**：APP（HarmonyOS）
   - **应用名称**：`小伴作业`
   - **应用包名**：`com.gyguan.homeworkassistant`

     > ⚠️ **中间没有连字符**！不要写成 `com.gyguan.homework-assistant`，AGC 会直接报「应用包名不符合规范」。
     >
     > HarmonyOS 包名规则（官方）：以点号分隔、**至少三段**，每段**只允许英文字母、数字、下划线 `_`**；
     > 首段以字母开头，每段以字母或数字结尾；长度 7~128 字符；
     > 且不能把保留字符单独作为一段（`oh` / `ohos` / `harmony` / `harmonyos` / `openharmony` / `system`）。
     >
     > 这里填的值必须与 `AppScope/app.json5` 里的 `bundleName` **完全一致**。
   - **支持设备**：勾选 **手机**、**平板**
   - **应用分类**：一级 `教育` → 二级 `学习工具`（或最接近的）
   - **默认语言**：简体中文
4. 点击 **创建应用**，等待创建完成。

## 三、在 DevEco Studio 上传 .app 包（AGC 云管理证书自动签名）

DevEco 26.0.0+ 支持在上传时由 AGC 云端自动签名，因此**无需手动申请发布证书**。

### 3.1 ⚠️ 中英文菜单名对照（最容易卡住的地方）

DevEco Studio 默认安装带**中文语言包**，菜单显示的是中文，按英文找一定找不到。
下面左列是官方文档里的英文写法，右列是你在 IDE 里实际看到的中文：

| 官方文档（英文） | 你的 IDE 实际显示（中文） |
| --- | --- |
| **Build** 菜单 | **构建** 菜单 |
| Build Hap(s)/APP(s) | **编译 Hap(s)/APP(s)** ← 注意是「编译」不是「构建」 |
| Build APP(s) | **编译 APP(s)** |
| **Upload Product** | **上传产品** ← 不叫「上传软件包」 |

英文版 IDE 的路径：`Build > Build Hap(s)/APP(s) > Build APP(s)`，然后 `Build > Upload Product`。
**中文版 IDE 的路径**：`构建 > 编译 Hap(s)/APP(s) > 编译 APP(s)`，然后 `构建 > 上传产品`。

> 💡 最快的方式：按 **Shift + Shift** 打开 Search Everywhere，直接输入 **`上传产品`**（或 `Upload Product`），
> 回车即可执行，完全不用在菜单里翻。

### 3.2 操作步骤

1. 打开 DevEco Studio，打开本项目 `D:\code\harmonyos-homework-assistant`。
   （必须从 IDE 里打开这个工程，「上传产品」是**工程级**菜单项，没有打开工程时不会出现。）
2. 菜单栏 → **构建 > 编译 Hap(s)/APP(s) > 编译 APP(s)**，等待构建完成。
   - 构建产物路径：`build\outputs\default\harmonyos-homework-assistant-default-signed.app`
   - **必须先构建出 .app**，「上传产品」只列出 `build/outputs` 下的软件包，没有包时列表是空的。
3. 菜单栏 → **构建 > 上传产品**（在「构建」菜单里，位置偏下）。
4. 如果未登录，点击 **Sign in**，用同一个已实名的华为开发者账号登录。
   - ⚠️ 必须用**已实名认证**的账号；且该功能**仅支持中国境内**（港澳台除外）。
5. 登录成功后，确认用户名和团队信息；在 App 包列表中选择刚才构建出的 `harmonyos-homework-assistant-default-signed.app`。
6. 点击 **Distribute App** → 上传类型选择 **AppGallery Connect**。
7. 签名方式保持默认 **Automatically manage signing**（使用 AGC 云管理证书自动重签名）。
8. 检查软件包信息，确认包名（`com.gyguan.homeworkassistant`）、版本号无误后，点击 **Upload** 上传。
9. 上传成功后，点击 **AppGallery Connect** 跳转到后台查看上传记录。
   - 上传完成后 `build/outputs` 下会多出一个 `re-signed.app`，这是 AGC 云管理证书重签名的产物，属**正常现象**，原 `.app` 不受影响。

### 3.3 「找不到菜单」自查表

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 「构建」菜单里只有「编译 Hap(s)/APP(s)」，没有「上传产品」 | IDE 版本低于 5.0.5.200 | 升级 DevEco Studio（26.0.0+ 才有云管理证书） |
| 整个「构建」菜单都找不到 | IDE 界面是中文，在找英文 "Build" | 认准**「构建」**菜单 |
| 「上传产品」是灰的 / 点了没反应 | 没打开工程，或工程未同步完成 | 先打开工程并等待 Sync 完成 |
| 上传界面 App 包列表是空的 | `build/outputs` 下没有 .app | 先执行「编译 APP(s)」 |
| 登录后提示「账号未实名认证，不支持该功能」 | 开发者实名认证未完成，或已完成但 IDE 未刷新 | 去开发者联盟完成实名（银行卡认证实时），**然后 Sign out 重新登录**，详见 Q0.5 |

## 四、在 AGC 创建邀请测试版本（外部公开链接）

> 📖 **本节已细化为独立手册：`AGC_TEST_VERSION_STEP_GUIDE.md`**
> 含逐屏逐字段的填法、隐私声明托管服务完整操作、公开链接的准确获取位置、
> 版本状态流转、测试有效期与常见卡点速查。**建议对照该手册操作**，下面是流程概览。

1. 进入 AGC → **我的应用** → 选择 **小伴作业** → 进入 **分发** 页面。
2. 左侧导航 → **应用测试/元服务测试 > 版本列表** → 右上角 **创建测试版本**。
3. 弹窗中：
   - **测试类型**：选择 **邀请测试**（弹窗里的单选；不要和下一屏的「测试阶段」字段混淆）
   - **版本描述**：例如 `0.1.0 首次邀请测试`
   - 点击 **确定**
4. 在 **版本信息配置** 页面填写：
   - **测试时间**：开始时间选今天，结束时间最长可选 90 天后。
   - **支持设备**：默认已勾选手机、平板，保持即可。
5. **配置软件版本** → 点击 **版本选取** → 选择上一步上传的软件包 → 点击 **选取**。
6. **配置测试信息**：
   - **语言**：简体中文
   - **应用图标**：上传 `store-assets/app_icon_1024.png`（或 `app_icon_216.png`）
   - **应用名称**：`小伴作业`
   - **应用介绍**（可直接复制）：
     ```
     小伴作业是一款面向单个家庭的 HarmonyOS AI 作业管家，帮助家长完成作业导入与管理，帮助孩子按任务完成学习，并通过 AI 辅导、作业提交和家长验收形成完整闭环。

     主要功能：
     · 作业导入与整理：支持文字、截图 / OCR 等方式导入老师作业，由 AI 整理为结构化任务；
     · 家庭作业管理：面向单家庭、多孩子，按科目、日期、类型和状态统一管理；
     · 学习空间：孩子按任务逐项完成，支持单任务计时与状态管理；
     · AI 小伴辅导：学习过程中可向 AI 提问，以引导思考为主；
     · 作业提交：完成后可上传多张作业照片；
     · 家长验收：家长查看完成情况，对提交内容进行通过或退回；
     · 学习进度：家长查看作业完成、待处理和整体进度。

     本产品仅服务单个家庭，不做班级社交、排行榜或在线课堂。
     ```
   - **测试说明**：
     ```
     0.1.0 首次邀请测试版本，包含家长端作业管理、孩子学习空间、AI 辅导、作业提交与验收等核心闭环，欢迎反馈稳定性与体验问题。
     ```
7. **配置隐私声明**：
   - 推荐选择 **使用隐私声明托管服务生成隐私声明**。
   - 按页面提示到「协议服务」生成隐私政策和用户协议，生成后在当前页面下拉框中选择。
   - 如果已有隐私政策 URL，也可选择「自定义隐私政策」并填写网址。
8. **是否向测试用户展示当前最新在架版本的应用截图**：
   - 首次测试没有在架版本，保持**不勾选**即可。
   - 如果后续需要补截图：手机 **16:9**、平板 **3:2**，数量 **3~10 张**（详见官方《素材规范》）。可从已安装真机截取。
9. **联系方式**（大陆开发者必填）：填写应用负责人姓名和手机号。
10. **补充应用审核信息**：
    - **需要登录进行审核**：✅ 勾选
    - **测试账号**：`parent`
    - **测试密码**：`parent123`
    - **备注**：
      ```
      1. 首次打开应用需登录上述账号才能使用核心功能。
      2. 后端服务地址已预置为 http://192.144.143.141:8080，审核时请确保网络可访问该公网地址。
      3. AI 辅导功能调用智谱大模型，需联网使用。
      4. 应用仅面向单家庭场景，无用户生成内容、无社交、无支付。
      ```
11. **上架自检**：选择 **否**（仅提交邀请测试审核，不进行正式上架自检）。
12. 点击右上角 **下一步**，进入 **选择测试用户**。
13. 选择**外部测试群组**（只有外部群组才支持公开链接）。
    - **建议提前创建**：左侧导航 →「应用测试 > **测试用户**」→「**外部测试用户群组**」→ 右上角「**创建测试群组**」→ 填群组名称（≤50 字符）→ 创建。
    - 也可在当前页点「**管理测试用户**」跳过去创建。
    - ⚠️ 公开链接是**群组级**的，必须先在「测试用户」菜单把群组建出来；它**不是**在群组设置里"开启生成"的，
      而是在版本进入「正在测试」后，到「测试用户 → 外部测试用户群组 → 该群组『管理』」的
      **添加测试用户页面**获取。用公开链接分发**不需要添加任何测试用户**，群组可以是空的。
14. 勾选该外部群组 → 点「**提交审核**」。
    - 这是**关键分叉**：勾了外部群组才会出现「提交审核」按钮、才需要过审核；
      若**仅**勾选内部群组，按钮是「**保存**」，免审核直接生效。
    - ℹ️ 实测本账号在「测试用户」里**只有「外部测试用户群组」页签，没有内部群组**——
      这是正常的（内部群组为 AppTest 专属能力，需应用已切换为 AppTest 邀请测试）。
      因此这个分叉对本项目**不存在**，按钮必然是「提交审核」。

## 五、获取公开链接并分享给家人

1. 提交审核后，版本状态变为 **正在审核**。
2. 外部邀请测试一般为 **分钟级审核**；通过后状态变为 **正在测试**。
3. 取链接路径：左侧导航「**应用测试 > 测试用户**」→「**外部测试用户群组**」→ 该群组「操作」列「**管理**」→「添加测试用户」页面 → **公开链接**。
4. 复制公开链接，通过微信/短信/QQ 等方式发给家人。

> ⚠️ 官方明确提示：「**任何人都可以分享此链接。因此，未经您直接邀请的用户也可能会加入您的测试群组。**」
> 只私发给家人，不要发到公开论坛或社交平台。

## 六、家人安装流程

1. 家人在 HarmonyOS 手机/平板上，用**系统浏览器**（不是微信内置浏览器）打开公开链接。
2. 页面会检测是否已安装 **AppTest**：
   - **已安装**：点击「前往 AppTest 查看」→ 进入测试应用详情页 → 接受邀请 → 点击安装。
   - **未安装**：先点击「前往应用市场查看」下载安装 AppTest → 返回公开链接 → 再点击「前往 AppTest 查看」→ 安装测试应用。
3. 安装完成后，打开「小伴作业」，使用 `parent` / `parent123` 登录。
4. 测试版本有效期最长 90 天；到期前可在 AGC 重新创建新的测试版本，链接会变，需重新分享。

> ⚠️ **必须从链接进入**：AppTest 邀请测试功能目前为**受限开放**，用户**无法直接在应用市场搜索到 AppTest**。
> 所以不要让家人自己去应用市场搜"AppTest"，一定让他们从公开链接走。

## 七、备选方案：手动发布证书路线

如果 DevEco Studio 没有 **构建 > 上传产品**（Build > Upload Product），或云管理证书上传失败，可按以下路线：

1. 在 DevEco Studio 生成 Key 和 CSR：**构建 > 生成私钥和证书请求文件**（Build > Generate Key and CSR），得到 `.p12` 和 `.csr`。
2. 在 AGC → **用户与访问 > 证书管理** → 新增证书 → 类型选 **发布证书** → 上传 `.csr` → 下载 `.cer`。
3. 在 AGC → 项目 → 应用 → **HarmonyOS 应用 > HAP Provision Profile 管理** → 添加 → 类型选 **发布** → 关联证书和应用 → 下载 `.p7b`。
4. 在本地 `build-profile.json5` 中配置发布签名（文件已加入 Git 忽略，不会入库）。
5. 命令行重新构建：`hvigorw assembleApp --mode project -p product=default -p buildMode=release`。
6. 在 AGC → **软件包管理** 中手动上传重新签名后的 `.app` 包。
7. 后续创建邀请测试版本的步骤与本指南第四、五节相同。

## 八、常见问题

**Q0：AGC 提示「应用包名不符合规范」怎么办？**
最常见的原因是**误用了连字符**。本项目的正确包名是 `com.gyguan.homeworkassistant`，
不是 `com.gyguan.homework-assistant`。HarmonyOS 包名每段只允许字母、数字、下划线，
不允许 `-`。另外还要确认：至少三段、总长度 7~128、没有把 `harmony`/`system` 等保留字单独作为一段。

**Q0.5：IDE 提示「账号未实名认证，不支持该功能」/「该功能仅限实名认证的开发者使用」怎么办？**

这是**开发者实名认证**没完成（或刚完成但**认证状态未同步到 IDE**）。

⚠️ 先分清两个概念：**华为账号实名** ≠ **开发者实名认证**。注册了华为账号、甚至做过华为账号实名，
**不等于**完成了开发者联盟的实名认证——DevEco 的自动签名 / 上传产品要的是后者。

**三步处理：**

1. **去认证**：登录 [华为开发者联盟](https://developer.huawei.com/consumer/cn/)
   → 点右上角头像下拉框的 **「去认证」**（或 **「管理中心」**）→ 选 **个人开发者**
   → 选认证方式：
   - **个人银行卡认证**（推荐，**实时生效**）：需银行卡**预留手机号与华为账号手机号一致**
   - 身份证人工审核（1~2 个工作日，慢）
   → 完善信息后签署《华为开发者联盟与隐私的声明》《华为开发者服务协议》并提交。
   （官方说明：<https://developer.huawei.com/consumer/cn/doc/start/itrna-0000001076878172>）

2. **⚠️ 认证完成后必须重新登录 IDE**（最容易漏的一步）：
   DevEco Studio **右上角个人中心 → Sign out 退出 → 重新登录**。
   IDE 会缓存认证状态，**不退出重登，即使已经实名也照样报这个错**。

3. **仍然报错**：IDE 的登录走内嵌浏览器，清一下浏览器 Cookie（**Ctrl+Shift+Del**）后重试。

**还要确认这几项：**

| 检查项 | 说明 |
|---|---|
| 登录账号是否就是已实名的那个 | IDE 右上角显示的账号必须与已完成实名的账号**同一个**，别用家人账号或团队子账号 |
| 实名是否**审核中** | 「管理中心 → 实名认证」显示「审核中」视为未完成，等通过 |
| 账号注册地 | 必须为**中国大陆**（IDE 原文：该功能仅限账号注册地为中国大陆地区的开发者使用） |
| 是否签署了分发协议 | AGC 首次进「应用信息」会弹**华为智慧分发平台合作协议**，需签署后才能继续上架 |

**如何在日志里确认是这个问题**（`%LOCALAPPDATA%\Huawei\DevEcoStudio26.0\log\idea.log`）：

```
AutoSigningConfigsService - responseContent is null, getUserTeamList   ← 取团队列表返回空
RequestAdapter - checkResponse is error. operation: 200 OK             ← HTTP 200 但业务码报错
```

`getUserTeamList` 返回 null 就说明该账号在 AGC 下没有可用的开发者主体 —— 即未实名或实名未生效。

**Q1：审核需要多久？**
外部邀请测试通常为分钟级基本审核；若为企业开发者首个构建版本可能需要标准审核。可在 AGC 版本列表查看状态。

**Q2：versionCode 下次怎么改？**
每次创建新的测试版本前，需递增 `AppScope/app.json5` 中的 `versionCode`（例如 `1000000` → `1000001`），然后重新构建 .app 包。

**Q3：家人不是华为设备能装吗？**
不能。AppTest 和 HarmonyOS 应用只能安装在华为/荣耀的 HarmonyOS 设备上。

**Q4：可以同时在多少设备上测试？**
外部测试群组累计去重用户上限为 10000 人，足够家庭使用。

**Q5：应用里的测试账号安全吗？**
`parent / parent123` 是专门用于审核和家庭初始化的测试账号，后端仅保存学习数据，没有支付或敏感个人信息。正式上线前建议移除或改为注册登录流程。
