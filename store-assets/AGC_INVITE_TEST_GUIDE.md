# 小伴作业 · AGC 邀请测试（公开链接）操作指南

> 目标：让家人通过公开链接直接安装「小伴作业」HarmonyOS 应用，无需数据线、无需收集家人华为账号。
>
> 适用版本：DevEco Studio 26.0.0 及以上（已确认当前环境为 26.0.0.821）。
>
> 路线：用 DevEco Studio 的 **Build > Upload Product** 让 AGC 自动完成发布签名，然后在 AGC 创建外部邀请测试并开启公开链接。

## 二、在 AGC 创建项目与应用

1. 用浏览器打开 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)，登录已实名的华为开发者账号。
2. 顶部导航 → **我的项目** → 点击 **添加项目**。
   - 项目名称：建议填 `小伴作业`（可改，仅用于后台管理）。
   - 数据处理位置：选择 **中国**。
3. 进入新项目后，点击 **添加应用**，按如下填写：
   - **平台**：APP（HarmonyOS）
   - **应用名称**：`小伴作业`
   - **应用包名**：`com.gyguan.homeworkassistant`
   - **支持设备**：勾选 **手机**、**平板**
   - **应用分类**：一级 `教育` → 二级 `学习工具`（或最接近的）
   - **默认语言**：简体中文
4. 点击 **创建应用**，等待创建完成。

## 三、在 DevEco Studio 上传 .app 包（AGC 云管理证书自动签名）

DevEco 26.0.0+ 支持在上传时由 AGC 云端自动签名，因此**无需手动申请发布证书**。

1. 打开 DevEco Studio，打开本项目 `D:\code\harmonyos-homework-assistant`。
2. 菜单栏 → **Build > Build Hap(s)/APP(s) > Build APP(s)**，等待构建完成。
   - 构建产物路径：`build\outputs\default\harmonyos-homework-assistant-default-signed.app`
3. 菜单栏 → **Build > Upload Product**。
4. 如果未登录，点击 **Sign in**，用同一个已实名的华为开发者账号登录。
5. 登录成功后，确认用户名和团队信息；在 App 包列表中选择刚才构建出的 `harmonyos-homework-assistant-default-signed.app`。
6. 点击 **Distribute App** → 上传类型选择 **AppGallery Connect**。
7. 签名方式保持默认 **Automatically manage signing**（使用 AGC 云管理证书自动重签名）。
8. 检查软件包信息，确认包名、版本号无误后，点击 **Upload** 上传。
9. 上传成功后，点击 **AppGallery Connect** 跳转到后台查看上传记录。

> 如果 DevEco 里没有 **Build > Upload Product** 菜单，说明该 IDE 版本不支持云管理证书。请切到本指南最后的「备选方案：手动发布证书路线」。

## 四、在 AGC 创建邀请测试版本（外部公开链接）

1. 进入 AGC → **我的应用** → 选择 **小伴作业** → 进入 **分发** 页面。
2. 左侧导航 → **应用测试/元服务测试 > 版本列表** → 右上角 **创建测试版本**。
3. 弹窗中：
   - **测试阶段**：选择 **邀请测试**
   - **版本描述**：例如 `0.1.0 首次邀请测试`
   - 点击 **确定**
4. 在 **版本信息配置** 页面填写：
   - **测试时间**：开始时间选今天，结束时间最长可选 90 天后。
   - **支持设备**：默认已勾选手机、平板，保持即可。
5. **配置软件版本** → 点击 **版本选取** → 选择上一步上传的软件包 → 点击 **选取**。
6. **配置测试信息**：
   - **语言**：简体中文
   - **应用图标**：上传 `store-assets/app_icon_1024.png`（或 `app_icon_216.png`）
   - **应用名称**：`小伴作业`
   - **应用介绍**（可直接复制）：
     ```
     小伴作业是一款面向单个家庭的 HarmonyOS AI 作业管家，帮助家长完成作业导入与管理，帮助孩子按任务完成学习，并通过 AI 辅导、作业提交和家长验收形成完整闭环。

     主要功能：
     · 作业导入与整理：支持文字、截图 / OCR 等方式导入老师作业，由 AI 整理为结构化任务；
     · 家庭作业管理：面向单家庭、多孩子，按科目、日期、类型和状态统一管理；
     · 学习空间：孩子按任务逐项完成，支持单任务计时与状态管理；
     · AI 小伴辅导：学习过程中可向 AI 提问，以引导思考为主；
     · 作业提交：完成后可上传多张作业照片；
     · 家长验收：家长查看完成情况，对提交内容进行通过或退回；
     · 学习进度：家长查看作业完成、待处理和整体进度。

     本产品仅服务单个家庭，不做班级社交、排行榜或在线课堂。
     ```
   - **测试说明**：
     ```
     0.1.0 首次邀请测试版本，包含家长端作业管理、孩子学习空间、AI 辅导、作业提交与验收等核心闭环，欢迎反馈稳定性与体验问题。
     ```
7. **配置隐私声明**：
   - 推荐选择 **使用隐私声明托管服务生成隐私声明**。
   - 按页面提示到「协议服务」生成隐私政策和用户协议，生成后在当前页面下拉框中选择。
   - 如果已有隐私政策 URL，也可选择「自定义隐私政策」并填写网址。
8. **是否向测试用户展示当前最新在架版本的应用截图**：
   - 首次测试没有在架版本，保持**不勾选**即可。
   - 如果后续被要求补截图，可用 `hdc shell snapshot_display` 从已安装真机截取，尺寸按华为素材规范（手机 1080×1920 或 1920×1080，平板 1280×1920 或 1920×1280）。
9. **联系方式**（大陆开发者必填）：填写应用负责人姓名和手机号。
10. **补充应用审核信息**：
    - **需要登录进行审核**：✅ 勾选
    - **测试账号**：`parent`
    - **测试密码**：`parent123`
    - **备注**：
      ```
      1. 首次打开应用需登录上述账号才能使用核心功能。
      2. 后端服务地址已预置为 http://192.144.143.141:8080，审核时请确保网络可访问该公网地址。
      3. AI 辅导功能调用智谱大模型，需联网使用。
      4. 应用仅面向单家庭场景，无用户生成内容、无社交、无支付。
      ```
11. **上架自检**：选择 **否**（仅提交邀请测试审核，不进行正式上架自检）。
12. 点击右上角 **下一步**，进入 **选择测试用户**。
13. 选择**外部测试群组**（只有外部群组才支持公开链接）。
    - 如果没有外部群组，点击 **管理测试用户** → 外部测试用户群组 → **创建测试群组** → 填写群组名称 → 创建。
    - 进入该群组管理页 → 在群组设置/邀请方式中开启 **生成公开链接**。
14. 回到版本页面，勾选该外部测试群组 → 点击 **提交审核**。

## 五、获取公开链接并分享给家人

1. 提交审核后，版本状态变为 **正在审核**。
2. 外部邀请测试一般为 **分钟级审核**；通过后状态变为 **正在测试**。
3. 进入该测试版本的 **测试用户** 页签，找到外部测试群组的 **公开链接**。
4. 复制公开链接，通过微信/短信/QQ 等方式发给家人。

> ⚠️ 公开链接任何人都能打开，请勿发到不可控的公开论坛或社交平台。

## 六、家人安装流程

1. 家人在 HarmonyOS 手机/平板上，用**系统浏览器**（不是微信内置浏览器）打开公开链接。
2. 页面会检测是否已安装 **AppTest**：
   - **已安装**：点击「前往 AppTest 查看」→ 进入测试应用详情页 → 接受邀请 → 点击安装。
   - **未安装**：先点击「前往应用市场查看」下载安装 AppTest → 返回公开链接 → 再点击「前往 AppTest 查看」→ 安装测试应用。
3. 安装完成后，打开「小伴作业」，使用 `parent` / `parent123` 登录。
4. 测试版本有效期最长 90 天；到期前可在 AGC 重新创建新的测试版本，链接会变，需重新分享。

## 七、备选方案：手动发布证书路线

如果 DevEco Studio 没有 **Build > Upload Product** 或云管理证书上传失败，可按以下路线：

1. 在 DevEco Studio 生成 Key 和 CSR：`Build > Generate Key and CSR`，得到 `.p12` 和 `.csr`。
2. 在 AGC → **用户与访问 > 证书管理** → 新增证书 → 类型选 **发布证书** → 上传 `.csr` → 下载 `.cer`。
3. 在 AGC → 项目 → 应用 → **HarmonyOS 应用 > HAP Provision Profile 管理** → 添加 → 类型选 **发布** → 关联证书和应用 → 下载 `.p7b`。
4. 在本地 `build-profile.json5` 中配置发布签名（文件已加入 Git 忽略，不会入库）。
5. 命令行重新构建：`hvigorw assembleApp --mode project -p product=default -p buildMode=release`。
6. 在 AGC → **软件包管理** 中手动上传重新签名后的 `.app` 包。
7. 后续创建邀请测试版本的步骤与本指南第四、五节相同。

## 八、常见问题

**Q1：审核需要多久？**
外部邀请测试通常为分钟级基本审核；若为企业开发者首个构建版本可能需要标准审核。可在 AGC 版本列表查看状态。

**Q2：versionCode 下次怎么改？**
每次创建新的测试版本前，需递增 `AppScope/app.json5` 中的 `versionCode`（例如 `1000000` → `1000001`），然后重新构建 .app 包。

**Q3：家人不是华为设备能装吗？**
不能。AppTest 和 HarmonyOS 应用只能安装在华为/荣耀的 HarmonyOS 设备上。

**Q4：可以同时在多少设备上测试？**
外部测试群组累计去重用户上限为 10000 人，足够家庭使用。

**Q5：应用里的测试账号安全吗？**
`parent / parent123` 是专门用于审核和家庭初始化的测试账号，后端仅保存学习数据，没有支付或敏感个人信息。正式上线前建议移除或改为注册登录流程。
