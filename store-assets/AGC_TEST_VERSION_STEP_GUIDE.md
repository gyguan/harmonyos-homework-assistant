## 零、先理清顺序：这一步不是"从头开始"

很多人卡住是因为**跳过了前置**，导致后面下拉框是空的。正确顺序是：

```
① 创建应用（已完成）
        ↓
② 上传软件包 ──→ 在左侧「软件包管理」里能看到 .app
        ↓
③ 创建外部测试群组 ──→ 公开链接是「群组级」的，没群组就没有链接
        ↓
④ 创建测试版本（本节重点）
        ↓
⑤ 提交审核 → 通过 → 版本变「正在测试」
        ↓
⑥ 回群组页面拿公开链接 → 发家人
```

**顺序不能颠倒的点**：第 ③ 步必须早于第 ⑥ 步；而第 ④ 步选软件包时，包必须已经在第 ② 步上传过，否则「版本选取」是空的。

### 前置检查（30 秒）

登录 [AGC](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) → 顶部「**APP与元服务**」→ 在 **HarmonyOS** 页签点应用「小伴作业」→ 进入应用页面后：

| 检查项 | 在哪看 | 期望结果 |
|---|---|---|
| 应用已创建 | 应用列表能看到「小伴作业」 | ✅ |
| 软件包已上传 | 左侧「**软件包管理**」 | 列表里有 `harmonyos-homework-assistant-default-signed.app` |
| 包名一致 | 同上，软件包详情 | `com.gyguan.homeworkassistant` |

若「软件包管理」是空的 → 回 DevEco Studio 走「构建 > 上传产品」，或手动上传
`build\outputs\default\harmonyos-homework-assistant-default-signed.app`。

## 一、创建外部测试群组（必须先做）

**路径**：左侧导航 →「**应用测试 > 测试用户**」→ 切到「**外部测试用户群组**」页签 → 右上角「**创建测试群组**」

| 字段 | 怎么填 |
|---|---|
| 群组名称 | 例：`家人测试`（≤50 字符） |

点「创建」。

> **为什么一定要建外部群组？** 公开链接是**群组级**的，没有群组就没有公开链接。
> 内部群组只能靠"提前把每个家人的华为账号加进去"来分发，需要一个个收集账号，我们不走这条。

### 公开链接在哪拿？

群组建好后：**「外部测试用户群组」→ 该群组的「操作」列 →「管理」→ 进入「添加测试用户」页面**，页面上就有**公开链接**。

⚠️ 现在**先不用去复制**——链接要等版本审核通过、进入「正在测试」状态后才有效。现在只要确认群组建好了即可。

### 关于「添加测试用户」

用公开链接分发**不需要添加任何测试用户**，群组可以是空的，链接照样能用。这也是公开链接最大的好处：无需提前收集家人的华为账号。

如果你想同时用邮件邀请（比如给某个家人单独发邀请码），注意两条现行规则：

- **短信邀请已停用**，统一走邮件；
- 华为账号必须是**邮箱格式或手机号格式**；手机号要写成 `86-13012345678`（**不是** `0086-`），国家码不带国际冠码。

## 二、创建测试版本

**路径**：左侧导航 →「**应用测试 > 版本列表**」→ 右上角「**创建测试版本**」

弹出「创建测试版本」窗口：

| 字段 | 填什么 | 说明 |
|---|---|---|
| 测试类型 | **邀请测试** | 另一个选项是公开测试，我们不选 |
| 版本描述 | `V2 首轮家庭测试` | ≤30 字符；**仅供你自己区分版本，不会展示给测试用户** |

点「**确定**」→ 自动进入「**版本信息配置**」页面。

## 三、配置版本信息（第一屏）

| 字段 | 填什么 | 官方说明 / 坑 |
|---|---|---|
| **测试阶段** | 默认即可 | **创建时选定，之后不可修改** |
| **测试时间** | 开始时间填**当前时间或今天**；结束时间按需（建议 30 天） | 只有到了开始时间，用户才能用公开链接下载。**最大有效期 90 天**。到期后未下载的用户无法再参与 |
| **支持设备** | 保持「手机」+「平板」勾选 | 默认勾选创建应用时选的类型。选「手机」时，即使包里没声明平板/PC，也会兼容分发到平板/PC |
| **发布版本** | 点「**版本选取**」→ 选中已上传的 `.app` → 「选取」 | **一个测试版本只能选一个软件包**。列表为空 = 软件包还没上传 |
| **版本描述** | 可沿用或修改 | ≤30 字符 |

### ⚠️ 版本号规范（最容易卡在这里）

| 规则 | 本应用情况 |
|---|---|
| VersionName 为 `A.B.C` 格式（数字 + 小数点）；VersionCode 为正整数 | `0.1.0` / `1000000` ✅ |
| 测试版本的 VersionCode **必须高于**已发布的全网版本 | 尚未发布全网版本，无冲突 ✅ |
| 测试版本 VersionCode **不能低于**已发布的测试版本 | 这是第一个测试版本 ✅ |
| **不允许两个在架测试版本的 VersionName + VersionCode + BuildVersion 完全一致** | 首个版本无冲突 ✅ |

**下次再发测试版时**：先把 `AppScope/app.json5` 里的 `versionCode` 从 `1000000` 递增（如 `1000001`），
`versionName` 改为 `0.1.1`，重新打包，否则提交会报版本号冲突。

## 五、配置隐私声明（第三屏 · 最容易卡）

两种方式，**推荐第 2 种**：

### 方式 1：自定义隐私政策（需要你自己有网站）

| 字段 | 说明 |
|---|---|
| 隐私政策网址 | 用户可访问、了解应用如何处理敏感用户数据与设备数据的**网页** |
| 隐私权利 | 用户实施其权利的网站，如删除 / 修改 / 导出个人数据的入口 |

⚠️ 要求是标准的 `http(s)://` **静态 HTML 页面**，不能是 PDF / Word，也不建议用博客、GitHub 页面凑数；
**应用内展示的政策必须与该 URL 内容一字不差**。本项目没有维护此类站点，**不走这条路**。

### 方式 2：隐私声明托管服务（推荐）

AGC 基于标准化模板帮你生成隐私政策与用户协议，还能让应用内自动使用标准化首启弹窗。

**关键前提：不能直接在测试版本页面选，必须先去「协议服务」把协议生成出来，下拉框里才会有内容。**

**操作步骤**：

1. **先离开当前页面**，去左侧导航 →「**服务 > 协议服务**」→「**新建协议**」
2. 「协议类型」选 **隐私政策**，填「协议名称」（如 `小伴作业隐私政策`），选「默认语言」**简体中文** → 「**下一步**」
3. 按模板逐模块填写（见下表），完成后「保存」
4. 如需用户协议，重复一次，协议类型选 **用户协议**
5. **回到「创建测试版本」页面**，在「隐私声明」区域的下拉框里就能选到刚生成的内容了

> 提示：托管服务支持保存为**草稿态**，填完整后需提交才能变为**完成态**，下拉框才选得到。

#### 托管服务各模块怎么填

**① 导语**

| 字段 | 填什么 |
|---|---|
| 产品简介 | `小伴作业是一款面向单个家庭的 HarmonyOS 作业管理应用，帮助家长导入并确认老师布置的作业，帮助孩子按任务完成学习，并提供引导式的 AI 学习辅导。` |
| 版本变更说明 | 首次发布，填 `首次发布。` |
| 摘要 | 概要说明收集、处理个人信息的目的、方式与范围（模板有引导语，照填即可） |

**② 「我们如何收集和使用您的个人信息」**

点「**增加数据信息**」，逐条填写业务场景并勾选数据项（**最多 200 条**）。

本应用**实际涉及**的数据项，按下面几组声明：

| 业务场景 | 对应数据项 | 说明 |
|---|---|---|
| 家长 / 孩子账号登录 | 账号信息（登录名）、密码 | 密码在服务端以哈希存储 |
| 建立孩子档案 | 姓名、年级、班级、学校 | 用于孩子端展示与作业归属 |
| 导入老师作业 | 用户粘贴的文字、上传的作业截图 | 截图经 OCR 转文字后由 AI 整理为任务 |
| 作业提交 | 用户拍摄或选择的作业照片 | 形成可追溯的提交记录 |
| AI 小伴辅导 | 提问的文字内容、拍题图片 | 用于生成引导式回答 |
| 家庭数据同步 | 上述作业与提交数据 | 通过家庭云端在家长端与孩子端之间同步 |

> ⚠️ **只声明实际收集的项**。多声明与少声明都可能引发审核质疑，
> 判断标准就是「不提供这项，该功能还能不能用」。

**③ 「设备权限调用」**

点「**添加权限及使用说明**」，勾选权限并填写用途。

> 🔴 **官方硬校验：此处声明的权限必须与软件包中实际配置的权限一致，否则无法提交审核。**

本应用 `entry/src/main/module.json5` 的 `requestPermissions` **只有一项**：

| 勾选权限 | 用途填写 |
|---|---|
| `ohos.permission.INTERNET` | `用于访问家庭云端服务，同步作业数据、提交记录以及使用 AI 辅导功能。` |

**只勾这一项**。相机与相册选图走系统 Picker，包内未声明对应权限，所以这里**不要勾**。
（若你在表单里勾了 `CAMERA` 之类包内没有的权限，提交时会被拦下。）

**④ 「与第三方共享个人信息清单」/「第三方 SDK」**

本应用清单：

| 第三方 | 数据项 | 用途 | 说明 |
|---|---|---|---|
| 智谱 AI（北京智谱华章科技） | 作业文本、提问内容、题目图片 | 作业结构化整理、AI 辅导回答 | 通过其开放平台 API 调用 |

> 这两个模块同时起到满足监管「**双清单**」要求的作用。若暂无第三方共享，选择"无"也要如实勾选。

## 八、补充应用审核信息（测试账号）← 你点名的这步

官方字段名是「**补充应用审核信息**」，作用是让华为审核人员能登录进去把功能走一遍。

| 字段 | 怎么填 | 说明 |
|---|---|---|
| **需要登录进行审核** | ☑ **勾选** | 本应用家长端需要登录后才能使用 |
| **测试账号** | `parent` | |
| **密码** | `parent123` | |
| **备注** | 见下方草稿 | 帮审核员少走弯路 |

### 「备注」草稿（可直接复制）

```
一、角色说明
应用分为家长端与孩子端，同一账号登录后可切换。测试账号为家长角色，可查看全部功能。

二、审核路径建议
1. 启动应用，使用上述账号登录（需联网，服务端部署在公网）。
2. 家长端「导入」：粘贴任意一段作业文字（例：语文：朗读课文3遍，明天带跳绳），
   点击 AI 整理，等待生成结构化任务列表，确认后发布。
3. 切换到孩子端「首页」，可看到刚发布的作业，点「开始」进入学习空间，
   支持计时、暂停、续做。
4. 学习空间内可向「AI 小伴」提问（文字即可），观察是否以引导和分步提示回答。
5. 完成一项后拍照提交，回到家长端「进度」，对该提交做「通过」或「退回订正」。
6. 家长端「进度」可查看今日/本周完成情况。

三、注意事项
- 应用必须联网使用；若提示连接失败，请检查网络后重试。
- AI 整理与 AI 辅导为在线大模型能力，响应需数秒，属正常。
- 测试数据用于功能验证，可能包含演示用作业内容。
- 若需新建孩子档案：家长端「我的 > 孩子档案」可添加。
```

> ⚠️ 两点提醒：
> 1. 这个账号密码会**展示给华为审核人员**，是提交审核的必需材料，但请确认该账号下**没有真实敏感数据**
>    （当前是测试家庭、演示数据，可以放行）。审核结束后建议改一次密码。
> 2. 审核人员会真实调用云端 AI 接口，**会产生智谱 API 消耗**，属正常，不必担心。

## 九、上架自检

| 选项 | 含义 | 建议 |
|---|---|---|
| **是** | 按**正式上架**的审核要求做自检，**预计 1 天**完成 | 如果你打算后续正式上架，选「是」，能提前暴露问题 |
| **否** | 仅提交邀请测试审核，不做上架自检 | 只想先跑通流程、尽快拿到链接，选「否」更快 |

> - 上架自检**不影响**邀请测试的上架结果；
> - 一个应用**同时只能有一个**自检中的任务，已有自检任务时不会再显示该选项。

| 字段 | 怎么填 |
|---|---|
| 自检报告通知 | 可勾选，自检不通过时会通过邮件和互动中心发报告 |

**我的建议**：首次选「否」，先把链接跑通、验证家人能不能装上；正式上架前再单独做一次自检。

## 十、选择测试用户并提交

配置完成后，点右上角「**下一步**」，进入「**选择测试用户**」步骤。

| 字段 | 说明 |
|---|---|
| 测试用户 | 勾选要参与本次测试的群组。**内部测试群组 ≤100 个，外部测试群组 ≤300 个，参与测试用户累计 ≤10000 个** |

点「**管理测试用户**」可快捷跳去「测试用户」菜单新增/修改群组。

**⚠️ 这一步决定了走不走审核，也决定了按钮叫什么：**

| 你勾了什么 | 按钮 | 结果 |
|---|---|---|
| 勾选了**外部群组** | 「**提交审核**」 | 需审核通过后才能开始测试 |
| **仅**勾选**内部群组** | 「**保存**」 | **免审核**，保存后即可测试 |

我们要公开链接 → 必须勾外部群组 → 点「**提交审核**」→ 进入「发布测试版本」页面。

> 这解释了为什么"公开链接通常分钟级审核"——外部（公开）测试需要过一次审核，
> 但邀请测试的审核很轻，通常是分钟级到数小时。

## 十一、等待审核：版本状态怎么看

提交后回到「**应用测试 > 版本列表**」，状态按下面的顺序流转：

| 状态 | 含义 | 你能做什么 |
|---|---|---|
| **正在审核** | 刚提交 | 可**撤销审核**，撤销后变「准备提交」 |
| **等待生效** | 审核通过，但还没到测试开始时间 | 可修改测试时间；可手动停止测试 |
| **正在测试** | 审核通过且已到开始时间 | ✅ **此时公开链接才生效**；可手动停止 |
| **审核不通过** | 被驳回 | 状态旁会显示**驳回原因**，按原因改后重新提交 |
| **已失效** | 手动停止 / 复测不通过 / 到达截止时间 | 已失效的版本可勾选后「批量删除」 |

**上架自检结果**（与版本状态分开显示）：

- `自检中`
- `测试完成` —— 存在**中等**问题，**可能**影响正式上架，建议修改
- `上架自检不通过` —— 存在**严重**问题，**影响**正式上架，**必须**修改
- `上架自检通过`

后两种情况可点「**上架报告**」查看详情（只做预审检测的按钮叫「查看报告」）。

> 小知识：版本列表会按 VersionName 归类。**没上传软件包的版本都归在「VersionName 未知」栏**；
> 上传后会自动归到对应栏目（如 `VersionName 0.1.0`）。看到"未知"就说明包没选上。

## 十二、拿到公开链接并分发给家人

版本进入「**正在测试**」后：

**取链接路径**：左侧导航「**应用测试 > 测试用户**」→「**外部测试用户群组**」→ 该群组的「操作」列「**管理**」→「添加测试用户」页面 → **公开链接**。

> 拿到后直接复制发给家人即可，**不需要**再拼接邀请码——这正是公开链接比邮件邀请方便的地方。

### ⚠️ 安全提醒（官方原文）

> "任何人都可以分享此链接。因此，**未经您直接邀请的用户也可能会加入您的测试群组**。"

所以：**只私发给家人，不要发到公开论坛、群聊、社交平台。**

### 家人端的操作（两步，取决于有没有装 AppTest）

**情况 A：没装 AppTest 客户端（大概率如此）**

1. 用**系统浏览器**打开公开链接（别用微信内置浏览器）；
2. 点第 1 步「**前往应用市场查看**」→ 跳转华为应用市场的 **AppTest** 详情页 → 下载安装 AppTest；
3. **返回公开链接页面**，点第 2 步「**前往AppTest查看**」；
4. 进入测试应用详情页 → **接受并安装**「小伴作业」。

**情况 B：已装 AppTest**

直接点「**前往AppTest查看**」→ 接受并安装即可。

> ⚠️ **重要**：AppTest 邀请测试功能目前是**受限开放**，用户**无法直接在应用市场搜索到 AppTest**，
> 必须从公开链接点进去。所以别让家人自己去应用市场搜，一定让他们从链接走。

## 十三、测试有效期与续期

| 规则 | 说明 |
|---|---|
| 测试时间最大有效期 | **90 天** |
| 到期后未下载的用户 | 无法再参与该版本的邀请测试 |
| 到期后**已参与**的用户 | 仍可继续测试，直至**安装时间满 90 天**，90 天后**应用将无法启动** |
| 能否改时间 | 状态为「等待生效」或「正在测试」时可改（提前启动、延长时间） |

**改测试时间**：版本列表 → 点该测试版本 → 「基础信息」栏 → 「测试时间」后的「**修改**」→ 选新的起止时间 → 「保存」。

⚠️ 两个细节：

- 「正在测试」状态下**不支持**修改测试**开始**时间；
- 处于「等待生效」时把开始时间改到当前之前，保存后会**立即**变为「正在测试」。

**想加群组**：在版本「选择测试用户」页点添加按钮即可。注意「审核不通过」和「已失效」的版本**不允许**添加群组，
且**群组只支持新增，不支持去除**。

## 十四、常见卡点速查

| 现象 | 根因 | 处理 |
|---|---|---|
| 「版本选取」列表是空的 | 软件包还没上传 | 先去「软件包管理」上传 `.app` |
| 提交报版本号冲突 | VersionCode 未递增 | 改 `AppScope/app.json5` 后重新打包上传 |
| 隐私声明下拉框选不到内容 | 没去「服务 > 协议服务」先生成协议 | 先生成隐私政策（并可提交为完成态），再回来选 |
| 提交审核被拦，提示权限不一致 | 权限清单勾选的与实际包内不符 | 只勾 `ohos.permission.INTERNET` |
| 家人点链接后装不上 / 提示无效 | 版本还没进入「正在测试」 | 等审核通过且到测试开始时间 |
| 家人搜不到 AppTest | 该功能受限开放，不可搜索 | 必须从公开链接点进去下载 |
| 版本列表显示「VersionName 未知」 | 该版本没关联软件包 | 进入版本补选软件包 |
| 测试版本 90 天后打不开 | 安装时间满 90 天，应用无法启动 | 重新发一版测试（并递增 versionCode） |

## 十六、可能被驳回的常见原因（提前规避）

| 风险点 | 说明 | 本应用状况 |
|---|---|---|
| 隐私政策与权限不一致 | 声明了包内没有的权限 | ✋ 已确认只声明 INTERNET，与包内一致 |
