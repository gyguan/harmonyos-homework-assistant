⚠️ 先看这里：鸿蒙不支持"点开 .hap 文件"安装 HarmonyOS（尤其纯血鸿蒙 / NEXT）没有给 .hap 关联安装程序，所以在手机上点下载好的 .hap 文件不会有任何安装动作（通常提示"暂无可用打开方式"或毫无反应）。 这不是安装包坏了，是系统的设计限制——和安卓点 APK 就装完全不同。

本页的下载链接是给电脑用的。安装必须在电脑上通过命令行完成，或者走华为官方的邀请测试通道。 下面两条路选一条。

1 电脑 + 命令行安装（最快，现在就能用）

  1. 用电脑点下面的按钮下载 .hap。
  2. 手机上开启「设置 → 系统和更新 → 开发人员选项 → USB 调试」， 用数据线连电脑；或手机与电脑连同一个 Wi-Fi，打开「无线调试」。
  3. 电脑命令行执行（`hdc` 在 DevEco Studio 的 sdk/default/openharmony/toolchains/ 目录下）：
# 有线：确认设备已连上
hdc list targets

# 无线：先用手机「无线调试」页面显示的 IP:端口 连接
hdc tconn 192.168.1.23:5555

# 安装（-r 表示覆盖安装）
hdc install -r homework-assistant-0.1.0.hap

看到 install bundle successfully 就装好了。 如果被系统拦下，先关掉「设置 → 系统和更新 → 纯净模式」再试。

2 华为邀请测试 · 点链接直接安装（真正的"分享链接"）

想让家人点一下链接就装上，唯一合规的办法是走华为官方的测试分发通道： 把应用上传到 AppGallery Connect 后创建邀请测试，生成分享链接。受邀者点链接 → 跳转华为应用市场 → 安装，不需要电脑也不用数据线。

  1. 需要一个已实名认证的华为开发者账号（个人开发者即可，免费）。
  2. 用发布证书 + 发布 Profile 重新签名打包（当前这份是调试证书，不能走市场分发）。
  3. 在 AGC 创建应用 → 上传包 → 创建邀请测试 → 拿到分享链接。

邀请测试（AppTest）内部测试模式免人工审核，100 个用户以内，一般几小时就能上架。

装好之后：连接云端

  1. App 默认后端地址已内置：http://192.144.143.141:8080， 也可在「设置 → 后端连接」里修改。
  2. 用家长账号登录（口令由家庭内部告知，本页不公开）。
  3. 登录后能看到「已连接：家长，家庭数据已同步」即为成功。
