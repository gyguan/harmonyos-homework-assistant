安装步骤

  1. 在本机系统浏览器中打开本页面（不要用微信内置浏览器）。
  2. 点上面的按钮下载 .hap 安装包，等下载完成。
  3. 打开「文件管理」→「下载」，找到 homework-assistant-0.1.0.hap，点击它。
  4. 系统弹出安装确认后，点击「继续安装」，完成。
  5. 首次打开若提示"不受信任"，进入设置 → 安全 → 更多安全设置，允许"外部来源应用安装"。
⚠️ 关于设备白名单 当前安装包使用华为开发者调试证书签名，只能安装在本开发账号已注册的设备上。
  • 已被授权的设备：平板 MatePad（已注册）
  • 如果换成其它手机安装失败，需要先用数据线连接电脑、开启「开发者选项 → USB 调试」，再重新签名一次，把该手机的设备号加入白名单。
  • 证书有效期至 2026-10-03，到期后需重新签名。

连接云端

  1. 安装后打开 App，进入「设置 → 后端连接」。
  2. 服务器地址：http://192.144.143.141:8080（已内置为默认值）。
  3. 用家长账号登录：parent / parent123。
